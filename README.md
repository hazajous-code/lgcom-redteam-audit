# Silent Exit Redteam — lg.com 화면 단위 As-Is / To-Be 진단

AI 가상 고객(레드팀)이 **lg.com UK · DE · TH**에 실제 진입해 페르소나별 구매 과업을 수행하고,
막힌 지점을 화면 구성 요소 단위로 특정한 뒤 캡처한 진단 리포트입니다.

**리포트 보기 → https://hazajous-code.github.io/lgcom-redteam-audit/**

## 무엇이 실측이고 무엇이 시뮬레이션인가

| 구분 | 성격 |
|---|---|
| 화면 실태 · 스펙 문자열 · 캡처 15장 | **실측** — 2026-08-25 lg.com에서 직접 관측 |
| 이탈률 · 도달 모수 · 마찰 지수 · VOC 발화 | **시뮬레이션** — AI 가상 고객이 생성. 실제 GA 트래픽이나 실제 고객 발언이 아님 |

## 주요 실측 결과

- UK PDP에서 `See All Specs`를 펼치면 스펙 텍스트가 **674자 → 4,531자**. 고객이 클릭 없이 보는 것은 **14.9%**
- 아코디언 초기 확장 개수 — UK **0 / 36**, TH **0 / 37** → **플랫폼 템플릿 문제**
- 치수 단위 표기는 **태국에만 `mm`이 있음**(`(WxHxD mm)`), UK·DE에는 없음 → **로컬 설정 문제**
- 같은 PDP가 상단은 `Up to 165Hz in 4K`, 스펙표는 `120Hz Native (VRR 165Hz)`
- Buying Guide 허브에서 **PLP·PDP로 나가는 링크 0개**
- TH 프로모션 허브의 Terms & Conditions 링크가 `href="null"`로 깨져 있음

## 구성

```
index.html      리포트 본문 (단일 파일, 캡처는 WebP data URI로 임베드)
shots/          원본 캡처 PNG
capture.py      Playwright 캡처 스크립트 (headed 필수)
cap2~4.py       추가 캡처 회차
```

## 재현 시 주의

lg.com은 엣지(Akamai)에서 **headless 브라우저를 403으로 차단**합니다.
캡처는 `headless=False`로만 동작합니다. 또한 스펙·리뷰가 지연 로딩되고
아코디언이 전부 접힌 채 시작하므로, 펼침 동작 후 판독해야 데이터의 15%가 아닌 전체를 관측할 수 있습니다.

## 고지

본 저장소는 공개 웹페이지를 관찰한 UX 진단 자료입니다.
캡처된 화면의 저작권과 상표권은 LG전자에 있으며, 각 캡처에는 출처 URL을 병기했습니다.
LG전자의 공식 자료가 아니며 회사의 입장을 대변하지 않습니다.
